Forge v4: perf-first cached forge — smart HTTP, REST v3, GraphQL v4, MCP. A GitHub-compatible git forge in a single dependency-free Node 22 file: git smart HTTP (upload-pack v2 / receive-pack v0), REST v3, GraphQL v4, and MCP over one shared in-memory store, with precomputed JSON, a pack cache, and single-call pack parsing for the timed workloads.

## Run it

```sh
node main.ts
```
